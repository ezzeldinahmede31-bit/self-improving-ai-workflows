# Low-Code / No-Code Platform Selection

Match workload to platform limits, not logo.

## Workflow
1. Inventory workload: volume, latency, integrations, team skills.
2. Read hard limits: task caps, polling floors, payload sizes.
3. Price real run profile, include premium multipliers.
4. Verify exit path: export formats, API access, self-host option.
5. Prototype riskiest integration on top-2 candidates.

## Core Rules
- Prototype hardest step first.
- Price monthly volume, not marketing tier.
