# Attention School

## Purpose

Distill attention/perception science into video rules. Single purpose: ATTENTION
— winning and holding the first 60 seconds. Deep pool: 90 works under
`attention-cognition` in `memory/psychology-books-index.json` (e.g. #422
Johnson, Developmental Cognitive Neuroscience).

## Core mechanisms (established science)

- Selective attention is scarce: System 1 decides in ~3s (Kahneman #14).
- Cognitive load: one new concept per beat; text+voice+gag simultaneously = drop.
- Von Restorff: the odd element is remembered — one visual shock per video.
- Primacy/recency + peak-end: strongest message first, CTA on resolved feeling.
- Re-hook every 15-30s: new promise, new visual, new question.

## Clinic rules

1. 0-3s: pain scene, never logo or greeting.
2. Burned Arabic captions (muted majority); cursor zoom on the money action.
3. One message per beat; silence before the key number.
4. End card: single WhatsApp keyword, 3 seconds hold.

## Verification

Every script must label: hook (with mechanism), beats (one message each),
re-hooks with timestamps, CTA placement. Missing label = rewrite.
