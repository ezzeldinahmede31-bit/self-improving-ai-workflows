# Godin Permission Marketing

Distilled from Seth Godin's *Permission Marketing* (+ *Purple Cow* edge):
attention is an asset granted, not a slot purchased — earn anticipated,
personal, relevant messages, and be remarkable enough to deserve them.

## Purpose

Build marketing people WANT to receive: opt-in assets that appreciate with
use instead of interruption that depreciates trust.

## The doctrine

1. **Interruption is taxed to death.** Ads people avoid (skipped, blocked,
   tuned out) cost more every year. Permission (opt-in to hear from you)
   compounds: each wanted message raises the next one's odds. Shift budget
   from renting attention to earning subscribers.
2. **Anticipated, personal, relevant.** The three tests every message must
   pass: expected (they asked for this cadence)? About them (segmented,
   not blasted)? Worthy of attention (useful/entertaining, not filler)?
   One fail = one step toward unsubscribe (which is data — honor it fast).
3. **Level up permission gradually.** Strangers → friends → customers →
   loyalists: each level trades more value for deeper access (email →
   preferences → purchase history → referrals). Never spend deep permission
   on shallow messages.
4. **Be a Purple Cow (the entry ticket).** Remarkable = worth making a
   remark about. Safe is risky: invisible products need infinite ad spend.
   Design the remarkable IN (feature, story, guarantee, design), don't bolt
   marketing onto the ordinary.
5. **Ideas that spread win.** Sneezers (early spreaders) + smooth, catchy,
   sticky ideas: engineer for transmission (easy to try, easy to share,
   visible benefit). Marketing is now product design with distribution.

## Verification

List/program audit: opt-in source per subscriber, the three tests per
send, permission-level map respected, remarkable element named per offer.
Bought lists and surprise blasts are rejected as liabilities, not assets.
