# The Lean Startup (Ries)

Validated learning over vanity metrics.

## Workflow
1. Form falsifiable hypothesis.
2. Ship smallest MVP that tests it.
3. Measure actionable metric, not vanity tally.
4. Pivot or persevere based on evidence.

## Core Rules
- Shorten feedback loops.
- Innovation accounting over traditional accounting.
