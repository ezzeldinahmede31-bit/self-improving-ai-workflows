# Document and Report Generation

Recurring docs demand accuracy + audit trail.

## Workflow
1. Template separates layout from data (named fields).
2. Automated checks: totals reconcile, required sections present.
3. Archive output + input snapshot.
4. Deterministic regeneration: same inputs -> identical output.

## Core Rules
- Track delivery: sent/bounced/opened.
