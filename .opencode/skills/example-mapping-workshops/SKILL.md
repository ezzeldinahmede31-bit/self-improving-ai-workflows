# Example Mapping Workshops

## Purpose

Slice stories thin with example mapping: story card, rules beneath, examples proving each rule, questions parked with owners.

## When to use

Use when the user says 'example mapping', 'story slicing', 'rules examples questions', 'discovery workshop', 'thin slice'.

## Steps

1. Place the story goal on top, sized to finish inside one sprint.
2. List rules (acceptance behaviors) beneath it.
3. Attach concrete examples to each rule until shared meaning clicks.
4. Park questions aside with named owners and due answers.
5. Split the story when rules cluster into independent slices.

## Anti-patterns

- Abstract rules with no examples attached.
- Questions parked without owners.
- Oversized stories mapped but never split.
- Mapping done solo and presented as decided.

## Example

Card layout: yellow story on top, blue rules row, green examples row, red questions row.

## Verification

Rules exemplified, questions owned, slices sprint-sized, mapping visible to the team.
