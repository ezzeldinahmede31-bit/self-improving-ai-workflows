# All of Statistics

## When to use
Use when statistics must be applied quickly and rigorously in data work, or when the user asks about statistical inference, the bootstrap, or confidence sets.

## Core mechanics
- Set up the probability foundation for the problem.
- Use the bootstrap for uncertainty estimates.
- Apply nonparametric methods when assumptions are weak.
- Fit regression and classification with their diagnostics.
- Use graphical models for structure.
- Report uncertainty with confidence sets.

## Verification
- Verify bootstrap intervals on synthetic data with known parameters.
- Check that assumptions hold on the data.
- Reproduce a textbook example end to end.
