# Machine Learning: An Algorithmic Perspective

## When to use
Use when the mechanics of a learning algorithm must be understood by implementing it, or when the user asks about perceptrons, backpropagation, or self-organizing maps.

## Core mechanics
- Implement each algorithm from its definition.
- Build the perceptron and multi-layer networks.
- Derive and code backpropagation.
- Implement radial basis functions, SVMs, and self-organizing maps.
- Add evolutionary and reinforcement approaches where appropriate.
- Test each implementation against a reference.

## Verification
- Verify each implementation reproduces a known result.
- Check learning curves converge on synthetic data.
- Compare the implementation against a library baseline.
