# Thinking, Fast and Slow (Kahneman)

Two systems drive judgment: fast intuition and slow reasoning.

## Workflow
1. Name the decision and the heuristic likely active (anchoring, availability, overconfidence).
2. Switch to System 2: state base rates, seek disconfirming evidence.
3. Design choice architecture that steers intuition correctly.
4. Verify via pre-mortem and reference class.

## Core Rules
- Never trust unaided intuition on high-stakes calls.
- Replace bias with process.
