# Hooked (Nir Eyal)

Habit is the moat.

## Workflow
1. Map user trigger (internal pain, external cue).
2. Design simplest action to relieve it.
3. Deliver variable reward (novelty, social, resource).
4. Ask for small investment that improves next cycle.

## Core Rules
- Manufacture desire ethically; test with real behavior.
- Frequency beats intensity for habit.
