# Clinic Buyer Psychology

## Purpose

Turn "Egyptian clinic owner" from a vague label into a precise psychographic
profile with named mechanisms, so every content/sales decision traces to a
reason. Single purpose: PROFILE the buyer. The content playbook lives in
`clinic-organic-sales-content`.

## When to use

- Before writing ANY sales content for the clinic system.
- When choosing offer framing, proof type, or CTA wording.
- When the user asks why a clinic owner would/would not buy.

## Steps

### 1. The buyer (evidence, not guesses)

Primary buyer: owner-dentist / owner-doctor of a 1-6 chair private clinic in
Cairo, Alexandria, or the Delta; secondary: clinic manager / head receptionist
who vetoes tools. Age core: **28-45** (graduation ~24-26 + 3-15 years to own a
clinic; Facebook Egypt's largest cohort is 25-34 per NapoleonCat Aug 2026, and
clinic-owner groups skew to the upper half of that band).

### 2. Psychographic profile

| Axis | Profile | Mechanism / source |
|---|---|---|
| Motivation | Protect daily revenue + professional prestige; wants the clinic to look modern without learning tech | Maslow esteem + competence; Clinit Egypt guide 2026: owners demand Arabic UI, EGP billing, WhatsApp engagement |
| Core fear | Empty chair = money burned; missed calls going to the competitor next door | Loss aversion (Kahneman & Tversky prospect theory, 1979/2011): losses weigh ~2x gains — frame as loss avoided |
| Pain (their words) | "العيان بيتصل ومحدش بيرد"، "الحجوزات بتضيع"، "السكرتيرة مشغولة"، "الناس بتحجز ومبتجيش" | Industry benchmarks: 30-38% of calls missed (Dental Economics); no-show 4-30%, avg ~15% (Denzif 2026 citing ADA); staffing shortages hit 90% (ADA) |
| Decision style | Deliberative on money, impulsive on pain: asks price fast, buys when a peer proves it | System 1 triggers on pain scenes; System 2 needs numbers before paying (Kahneman, Thinking, Fast and Slow, 2011) |
| Trust evidence | Peer clinics + hard numbers, not vendor promises | Social proof must be in-group (Cialdini, Influence, unity principle): "عيادة زي عيادتك" |
| Objection | "السيستم معقد"، "السكرتيرة مش هتعرف"، "بكام؟"، "الداتا هتضيع؟" | Answer each with one proof asset (screen video, price anchor, backup note) |

### 3. Messaging levers (pick per piece, never all)

1. **Loss framing first**: "كل مكالمة ضايعة = كرسي فاضي" beats "زود حجوزاتك". (Prospect theory.)
2. **In-group social proof**: one clinic name/story like theirs > any feature list. (Cialdini unity + social proof.)
3. **Authority by numbers**: cite the real stats — reminders cut no-shows ~23% (Parikh et al., Am J Med 2010, PMID 20569761; BMJ Open 2016 meta-analysis; Sesame dental study −22.95%, +$31,456 production). Never invent a stat.
4. **Commitment ladder**: free demo → small setup fee → monthly. Small yes first. (Cialdini commitment.)
5. **Honest scarcity only**: "بستلم 3 عيادات في الشهر" only if true. Never fake. (Ethics bound.)

### 4. Video-edit spec for this buyer

- Hook (0-3s): pain scene, never logo. Example: phone ringing, nobody answers.
  (System 1 + 3-second rule; attention data: hook decides retention.)
- Emotion: anxiety → relief arc; peak (money recovered) in last third; CTA on
  the resolved feel. (Ekman + peak-end rule.)
- One message per beat; screen recordings with Arabic captions (many watch
  muted). Re-hook every 15-30s. CTA single action: "ابعت (ديمو) واتساب".

## Verification

Before adopting any clinic-sales message, check: (1) loss framed, (2) proof is
in-group + real, (3) exactly one CTA, (4) every number has a source. If any
check fails, rewrite.
