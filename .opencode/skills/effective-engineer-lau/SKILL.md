# The Effective Engineer (Lau)

Maximize leverage: impact per time invested.

## Workflow
1. List tasks, estimate leverage (impact/effort).
2. Prioritize high-leverage: unblock others, automate, fix root causes.
3. Invest in learning loops: measure, reflect, adjust.
4. Build systems that multiply future output.

## Core Rules
- Work on what matters most, not what is loudest.
- Optimize for learning velocity.
