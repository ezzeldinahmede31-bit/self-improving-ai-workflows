## Clinic rules

1. One battlefield (Egyptian dental), one weapon (WhatsApp booking), one metric (booked demos).
2. Weekly numbers review per clinic; red metric = same-day fix.
3. Position against the old way (missed calls), never against a named rival publicly.
4. Build the moat: reminder data + reviews flywheel competitors can't copy in a quarter.

## Verification

Every strategy must state: battlefield, weapon, metric, review cadence — each
with its canon source. Missing item = incomplete strategy.
