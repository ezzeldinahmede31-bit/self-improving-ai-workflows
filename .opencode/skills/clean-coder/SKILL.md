# The Clean Coder: A Code of Conduct for Professional Programmers (Robert C. Martin)

The Clean Coder is about the character of a professional: honesty, responsibility, and discipline. This skill applies that code of conduct to everyday engineering decisions.

## Professionalism

- A professional is responsible for the code they ship, including its defects.
- Never promise what you cannot deliver; say no before the commitment is made.
- Continuous learning is part of the job; the craft moves and the professional moves with it.

## Saying no and estimation

- Refuse the impossible: an estimate is a statement of what can be done, not a number to be negotiated.
- Estimate with ranges and update them as knowledge grows.
- A professional commits to a plan only when it is achievable.

## Discipline and practice

- TDD, refactoring, and continuous integration are the disciplines that keep speed high.
- Practice deliberately; the craft improves with focused work.
- Time management protects the focus that deep work needs.

## The code of conduct

- A professional does not ship sloppy work and does not hide defects.
- Working with the team means communication, respect, and ownership.
- Do the right thing even when it is the hard thing; that is the definition of professional.
