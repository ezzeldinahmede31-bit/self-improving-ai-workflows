# Understanding Machine Learning

## When to use
Use when a model's learnability must be argued rigorously, or when the user asks about PAC learning, VC dimension, or generalization bounds.

## Core mechanics
- Frame learning with the PAC model.
- Bound generalization with uniform convergence and VC dimension.
- Relate bias and complexity to sample size.
- Analyze linear predictors and kernels with the theory.
- Use boosting with its guarantees.
- State the assumptions a guarantee relies on.

## Verification
- Verify a bound numerically on synthetic data.
- Reproduce the key theorems on a simple family of hypotheses.
- Test that the theory matches empirical error.
