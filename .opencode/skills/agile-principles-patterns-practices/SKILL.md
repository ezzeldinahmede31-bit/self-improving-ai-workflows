# Agile Software Development: Principles, Patterns, and Practices (Robert C. Martin)

This book connects agile delivery to the SOLID principles and the patterns that make code easy to change. This skill applies that connection to daily work.

## The agile principles

- Agile values working software, responding to change, and short feedback loops over process and documentation.
- Deliver in small increments; each increment is a decision point.
- The customer and the team collaborate continuously; the backlog is a living contract.

## The SOLID design principles

- Single Responsibility: a class has one reason to change.
- Open/Closed: open for extension, closed for modification; depend on abstractions.
- Liskov Substitution, Interface Segregation, and Dependency Inversion complete the set; each guards a specific failure.

## Patterns applied

- Patterns solve recurring design problems; name the problem before choosing the pattern.
- The Command, Strategy, Template Method, and others appear naturally in changeable systems.
- Prefer the simplest design that meets the requirement; a pattern is a tool, not a trophy.

## The practices

- Test-driven development and refactoring keep the design clean as requirements move.
- Small, frequent releases reduce the risk of every change.
- Clean code is not optional; it is how the team keeps its speed.
