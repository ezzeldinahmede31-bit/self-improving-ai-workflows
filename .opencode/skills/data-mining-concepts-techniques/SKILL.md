# Data Mining: Concepts and Techniques

## When to use
Use when a mining task spans the whole process, or when the user asks about data preprocessing, frequent patterns, association rules, or outlier detection.

## Core mechanics
- Preprocess data and design the warehouse layout.
- Mine frequent patterns and association rules.
- Apply classification and clustering.
- Detect outliers and anomalies.
- Handle structured and unstructured data.
- Evaluate the mining results against the business goal.

## Verification
- Verify preprocessing is lossless where it must be.
- Check association rules against the data on a small example.
- Evaluate classification and clustering on held-out data.
