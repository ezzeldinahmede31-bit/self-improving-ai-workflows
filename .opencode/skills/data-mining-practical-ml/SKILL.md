# Data Mining: Practical Machine Learning Tools and Techniques

## When to use
Use when mining a dataset with proven tools and techniques, or when the user asks about decision trees, rule learners, or evaluating a classifier with WEKA.

## Core mechanics
- Frame the mining task and prepare the data.
- Select attributes and handle missing values.
- Train decision trees, rules, and lazy learners.
- Apply Bayesian methods and clustering.
- Evaluate with cross-validation and the right metrics.
- Use the WEKA tooling as the reference implementation.

## Verification
- Evaluate on a held-out set with cross-validation.
- Verify that preprocessing choices are reversible and documented.
- Compare against a simple baseline.
