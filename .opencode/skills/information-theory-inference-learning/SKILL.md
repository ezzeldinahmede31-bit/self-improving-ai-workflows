# Information Theory, Inference, and Learning Algorithms

## When to use
Use when a problem needs the information-theoretic view of learning, or when the user asks about entropy, coding, or inference as a probability calculation.

## Core mechanics
- Measure information with entropy and related quantities.
- Apply the source-channel theorem to bound what a system can do.
- Treat inference as a probability calculation with the right prior.
- Use variational methods when exact inference is hard.
- Connect learning algorithms to their information-theoretic limits.
- Choose representations by their coding cost.

## Verification
- Reproduce textbook quantities on simple distributions.
- Verify a coding scheme against the entropy bound.
- Check that inference results agree with an exact method on a small case.
