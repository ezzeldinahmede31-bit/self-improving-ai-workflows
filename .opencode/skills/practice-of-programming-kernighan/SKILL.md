# The Practice of Programming (Kernighan & Pike)

Style and practice beat cleverness.

## Workflow
1. Write clear code: names, structure, comments for why.
2. Test systematically: boundaries, stress, regression.
3. Measure before optimizing; profile hot spots.
4. Portability: isolate platform assumptions.

## Core Rules
- Clarity first, then correctness, then performance.
- Automation over manual repetition.
