# Clinic Organic Sales Content

## Purpose

Turn the clinic system into booked demos with faceless organic content.
Single purpose: CONTENT + DISTRIBUTION + CLOSE. Buyer profile lives in
`clinic-buyer-psychology` — load it first.

## When to use

- Planning the 30-day calendar, writing a script, editing a faceless video.
- Choosing platforms, posting times, CTA, or DM replies.
- Measuring what worked and doubling down.

## Steps

### 1. Positioning (agency, not freelancer)

Sell as an **agency/brand** ("عيادة تك" style entity): pre-vetted team,
flat monthly fee, continuity if one person leaves. Reason: clinic owners buy
risk reduction; agencies signal continuity while freelancers signal
single-point-of-failure (Goods.). Face: never needed — screen recordings +
AI Arabic voiceover + captions carry B2B software sales.

### 2. Platform priority for Egypt (with source)

1. **Facebook Reels + Groups** — 51.6M users in Egypt, largest cohort 25-34
   (DataReportal Digital 2026 Egypt; NapoleonCat Aug 2026). Owner-dentists
   live in FB dental groups.
2. **TikTok** — 48.8M adults reached, +25.4% YoY growth (DataReportal 2025/
   2026 Egypt). Discovery engine for 28-38 owners.
3. **YouTube Shorts + 1 long demo** — 49.3M users (CAPMAS via CairoScene Apr
   2026). Shorts for reach, 8-min screen demo for closers.
4. **LinkedIn** — 18.07M (NapoleonCat). One repost per week for multi-branch
   owners. Instagram last (24.4M, younger/skewed B2C).

### 3. The 4 content pillars (rotate, 40/25/20/15)

1. **Pain + math (40%)** — missed-call loss, no-show cost, reception chaos.
   Real numbers only (Parikh 2010; BMJ Open 2016; Sesame −22.95%).
2. **Proof on screen (25%)** — Telegram/WhatsApp booking happening live,
   reminder sent, queue number issued, dashboard stats. No face, cursor + zoom.
3. **Objection killers (20%)** — "السكرتيرة هتعرف؟" (60-sec training clip),
   "بكام؟" (price anchor vs empty chair), "الداتا؟" (backup note).
4. **Authority (15%)** — Egypt specifics: WhatsApp >95% open vs SMS <30%
   (Clinit guide May 2026); Arabic UI + EGP billing checklist.

### 4. Faceless video template (45-60s)

0-3s hook (pain scene) → 3-15s agitate with one number → 15-40s screen proof
→ 40-50s objection line → 50-60s single CTA: "ابعت (ديمو) على واتساب".
Voice: AI Arabic VO; captions burned (muted viewing); one message per beat;
re-hook at ~20s. ($100M Offers-style value framing: outcome + time + ease;
Made to Stick: concrete + story; Contagious: practical value + story.)

### 5. Posting ops

- Volume: 4-5 short videos/week (FB + TikTok + Shorts same file, native
  captions per platform) + 1 LinkedIn text repost + 2 FB-group value posts.
- Times (Cairo): 1pm (clinic break) and 9-11pm (after clinic). Test 2 weeks,
  keep winners.
- Every post ends with the SAME WhatsApp CTA keyword ("ديمو") for tracking.

### 6. Close path (content → cash)

WhatsApp auto-reply → 3 qualifying questions (specialty? chairs? current
booking method?) → 8-min Loom-style demo link → paid pilot (setup fee +
month 1) → monthly retainer. Measure: views → WhatsApp starts → demos →
pilots → retained. Kill pillars with views but zero WhatsApp starts after
10 posts; double the pillar with the best start-rate.

## Verification

Weekly: pull per-video views + WhatsApp starts; every claim in new scripts
re-checked against `clinic-buyer-psychology` sources; no stat without URL;
no fake scarcity. Monthly: revenue per pillar.
