# Handley Everybody Writes

Distilled from Ann Handley's *Everybody Writes*: everyone in an organization
writes now — customers judge you by every sentence. Write simply, humanly,
and usefully, with process that prevents embarrassment.

## Purpose

Raise all writing to professional: clear voice, story habit, and a
publishing discipline that catches errors before readers do.

## The rules (writing + publishing)

**Writing:**
1. **Voice with a pulse.** Write like a person talking to a person (read
   aloud; if it sounds like a committee, rewrite). Second person liberally;
   contractions welcome; jargon translated or deleted.
2. **Show, don't tell (specifically).** Replace adjectives with evidence:
   not "robust solution" but "survives 10x traffic spikes without added
   servers". Details persuade; adjectives decorate.
3. **Story even in small things.** Open with tension or a human, structure
   with arc (setup → complication → resolution), close with the point
   earned. Product updates, emails, and docs all take story shape.
4. **Useful first, clever second.** Answer the reader's question before
   entertaining them. Headlines promise what the piece delivers (no
   curiosity debt without payoff). Scannable structure (heads, lists,
   short paragraphs) respects busy readers.

**Publishing (the unsexy half that matters):**
5. **Process beats talent.** Draft → rest → revise → second eyes → fact-
   check → publish checklist. Ugly first drafts mandatory (perfectionism
   upfront is procrastination in a suit).
6. **Voice-and-tone guide.** Documented do/don't examples per channel so
   anyone writing sounds like the brand. Inconsistency reads as
   untrustworthy — systematize it away.

## Verification

Piece review: read-aloud pass done, adjectives-to-evidence ratio checked,
story shape present, publishing checklist signed (facts, links, names,
numbers verified). "Good enough to ship" means checklist-green, not
author-tired.
