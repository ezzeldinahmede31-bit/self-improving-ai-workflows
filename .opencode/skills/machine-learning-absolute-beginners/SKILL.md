# Machine Learning for Absolute Beginners

## When to use
Use when the user is new to machine learning and needs the concepts explained plainly before any code: what the algorithms do, why data matters, and how a simple project works end to end.

## Core mechanics
- Machine learning finds patterns in data and makes predictions from them; supervised learning uses labeled examples, unsupervised learning finds structure without labels.
- Data is everything: clean, well-prepared, and representative data beats clever algorithms.
- A model is trained to fit the data and evaluated on data it has never seen.
- The main families: linear models, tree-based models, clustering, and neural networks — each fits a problem shape.
- Evaluation asks the honest question: does the model work on new data, not just the training data?
- Build one complete small project (import, clean, train, evaluate, predict) to connect every concept.

## Verification
- Complete the guided small project and explain each step in plain words.
- Confirm the model is evaluated on a held-out split, not the training data.
