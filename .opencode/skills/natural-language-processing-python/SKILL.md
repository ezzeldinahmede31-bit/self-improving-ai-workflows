# Natural Language Processing with Python

## When to use
Use when doing practical NLP in Python with the NLTK toolkit, or when the user asks to tokenize, tag, chunk, parse, or classify text with standard libraries.

## Core mechanics
- Access and explore corpora with the NLTK data interface.
- Process raw text into tokens and sentences.
- Tag parts of speech and chunk named entities.
- Parse sentences into trees and draw structure.
- Classify text with feature sets and evaluate the classifiers.
- Use the toolkit's built-in models as baselines before custom work.

## Verification
- Run the pipeline on a sample corpus and inspect token, tag, and parse output.
- Measure classification accuracy on a held-out test split.
- Verify the toolkit functions against the documented examples.
