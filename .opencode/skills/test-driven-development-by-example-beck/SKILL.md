# TDD By Example (Beck)

Tests drive design, not just verify it.

## Workflow
1. Write failing test for next tiny behavior.
2. Write minimal code to pass.
3. Refactor with tests guarding.
4. Repeat; keep cycle minutes-long.

## Core Rules
- Never write production code without a failing test.
- Keep tests fast, isolated.
