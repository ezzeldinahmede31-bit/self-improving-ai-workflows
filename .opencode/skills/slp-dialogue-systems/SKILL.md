# Dialogue Systems

## When to use
Use when a chatbot or voice assistant must be designed with a proper dialogue architecture, or when the user asks about dialogue state tracking or task-oriented dialogue.

## Core mechanics
- Model dialogue acts and the dialogue state.
- Track the state as the conversation progresses.
- Use frame-based and task-oriented designs for goal-driven conversations.
- Generate responses from the state and the model.
- Handle clarification and repair.
- Evaluate with task completion and user experience metrics.

## Verification
- Run a scripted dialogue and verify the state transitions.
- Test the system on out-of-scope user turns.
- Measure task completion on a test set.
