# Radical Focus (Nir Eyal)

Transfers the Indistractable discipline to long, high-stakes sessions: name the real triggers, commit to traction with timeboxed objectives, and remove the machinery that pulls attention away — so one objective is actually finished.

## When to use
- Starting a long, multi-step task where drift would be costly.
- Noticing the session pulling toward side tasks, curiosity trails, or context creep.
- Scheduling work so the load-bearing objective is timeboxed and finished first.

## The four-part model
1. Master internal triggers: when the urge to wander appears, name the emotion driving it and return to the planned objective instead of feeding it.
2. Make time for traction: plan each block as timeboxed work on the objective, not as an open-ended availability.
3. Hack back external triggers: silence or defer anything that interrupts the current block; batch them into a dedicated slot.
4. Prevent distraction with pacts: pre-commit the sequence of steps so the next action is always obvious.

## Discipline
- One objective at a time; timebox it, execute it, close it, then move on.
- Define the done-condition before starting so 'finished' is a fact, not a feeling.
- When a side thought surfaces, park it visibly and return; parked items are handled only in their own block.

## Verification discipline
- Check the original objective still governs the current action; any divergence is a trigger to re-anchor.
- Confirm each timebox produced its planned output before opening the next.
- End the session by stating what was actually completed versus what was deferred.
