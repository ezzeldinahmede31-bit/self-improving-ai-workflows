# Natural Language Processing in Action

## When to use
Use when an NLP system should be built working from a running prototype, or when the user asks about building a chatbot, information extraction, or text generation in Python.

## Core mechanics
- Start from a working pipeline and improve it.
- Move from bag-of-words to embeddings as the task demands.
- Build rule-based and learned components together.
- Construct chatbots with dialogue structure.
- Extract structured information from text.
- Generate text with modern models and control the output.

## Verification
- Run the prototype end to end on sample inputs.
- Measure task metrics on a held-out set.
- Test the chatbot on adversarial user turns.
