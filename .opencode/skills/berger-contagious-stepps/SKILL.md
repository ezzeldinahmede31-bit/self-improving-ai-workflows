# Berger Contagious STEPPS

Distilled from Jonah Berger's *Contagious*: virality is engineered, not
luck — six ingredients (STEPPS) make ideas spread, and each is designable.

## Purpose

Build shareability into content and products deliberately instead of hoping
for lightning.

## STEPPS (audit every piece against all six)

1. **Social Currency.** Sharing must make the sharer look good (smart,
   funny, in-the-know, helpful). Ask: does passing this on raise the
   sender's status? Remarkable = worth remarking about — engineer the
   remarkable detail in.
2. **Triggers.** Top-of-mind means tip-of-tongue: link the idea to frequent
   environmental cues (coffee-morning energy, Monday planning). Habit-adjacent
   triggers beat brilliant-but-rare ones.
3. **Emotion.** High-arousal emotions spread (awe, excitement, amusement,
   anger, anxiety); low-arousal (sadness, contentment) stalls. Design FOR an
   arousal state — content without emotional charge is content without fuel.
4. **Public.** Built to show, built to grow: visible usage teaches observers
   (Apple logo facing out, Movember mustaches). Make private behavior
   visible where ethics allow — observability is free advertising.
5. **Practical Value.** Useful news travels (money-saving, time-saving,
   health, how-tos). Package the useful part for forwarding (lists, steps,
   calculators) — friction kills practical sharing fastest.
6. **Stories.** Wrap the message in narrative (Trojan-horse stories carry
   the idea inside entertainment). The moral: nobody shares ads, everybody
   shares stories that happen to contain the idea.

## Verification

Shareability review scores 0-2 per STEPPS letter with the mechanism named
(trigger cue? emotion state? story vehicle?). Total under 6 = rewrite, not
more budget.
