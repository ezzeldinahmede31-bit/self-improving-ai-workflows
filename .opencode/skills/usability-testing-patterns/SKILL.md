# Usability Testing Patterns

## Purpose

Prove humans succeed: task-based sessions, think-aloud insight, measured completion, iterative fixes verified by retest.

## When to use

Use when the user says 'usability test', 'think aloud', 'task success', 'SUS', 'first-click test', 'user session'.

## Steps

1. Define tasks as user goals with success criteria, not click paths.
2. Observe a small set of users thinking aloud per round.
3. Measure completion plus time plus errors plus satisfaction.
4. Fix top issues first; retest with fresh users.
5. Track scores across releases as a quality signal.

## Anti-patterns

- Leading participants toward the designed path.
- Opinion debates replacing observed behavior.
- One big study instead of small iterative rounds.
- Findings filed without retest proof.

## Example

Task card: "Book a refund as a guest" with success, time, error, and SUS capture.

## Verification

Tasks goal-based, sessions observed, fixes retested, scores trended.
