# Zero to One (Thiel)

Competition erodes value; creation builds it.

## Workflow
1. Find a secret: valuable truth few believe.
2. Design monopoly via niche domination then scale.
3. Leverage power law: focus on the one thing that changes everything.
4. Build durable advantage (network, brand, tech).

## Core Rules
- Avoid perfect competition.
- Last mover advantage over first mover myth.
