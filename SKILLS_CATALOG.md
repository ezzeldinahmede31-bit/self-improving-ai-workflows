## Part 3 — Custom-Built (this project)

Designed and built here to make weak/free-tier LLMs behave like frontier models — then shared back so the network compounds:

- **Nightly Skill Evolver** (`skillopt-sleep`) — Learns from your sessions while you sleep: harvests transcripts, mines recurring tasks, replays them, and consolidates only held-out-validated improvements into memory and skills. Runs nightly via cron or on demand with make dev-cycle. [SKILL.md](.opencode/skills/skillopt-sleep/SKILL.md)
- **Measured Model Evolver** (`autonomous-model-self-evolver`) — Measures the current model against a live leader on deterministic probes, extracts real weaknesses from the rejection audit trail, and promotes a fix into an enforced rules.json only after the model passes the exact regression probe. No measured gap, no promotion — ever. [SKILL.md](.opencode/skills/autonomous-model-self-evolver/SKILL.md)
- **Internet Skill Discoverer** (`scripts/discover_skills.py`) — Derives search queries from today's work, searches skills.sh, fetches candidates, adapts their files programmatically (frontmatter, paths, adapter wrappers), security-scans them, and stages or adopts. Part of make dev-cycle. [source](scripts/discover_skills.py)
- **Shared Security Gate** (`scripts/security_scan.py`) — One scanner for all external content: exposed secrets (auto-fixable) and dangerous code (blocking). Used by discovery, update-apply, and the GitHub verify_update workflow. [source](scripts/security_scan.py)
- **Upstream Publisher** (`scripts/sync_upstream.py`) — Collects local improvements and opens a community-contributions PR to the central repo. Consent-gated; silent by default without approval. [source](scripts/sync_upstream.py)
- **Update Notifier** (`scripts/report_update.py`) — Notifies the central repo of a client update as a metadata-only GitHub Issue — shows you the exact text and requires explicit [y/n] approval. Nothing secret ever leaves. [source](scripts/report_update.py)
- **Update Acceptor** (`scripts/check_updates.py`) — Shows upstream releases with changelogs and lets you accept (local security scan + backup + apply) or reject (recorded forever) each one. Nothing auto-applies. [source](scripts/check_updates.py)
- **Consent Gate** (`scripts/setup_consent.py`) — Install-time consent: accept sharing (metadata-only + per-send approval) or decline into fully-local mode. Re-runnable any time via make setup. [source](scripts/setup_consent.py)

Also part of the engine: `build_gates_pipeline.py` (7-stage build gates), `build_skills_catalog.py` (this file's generator), `install_hook.sh`, and the GitHub workflows `ci.yml` + `verify_update.yml`.
