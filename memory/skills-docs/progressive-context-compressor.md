## What it does

Survives long sessions without losing fidelity: instead of a single late collapse, maintains a rolling structured summary as the conversation grows, decides WHAT is droppable and WHAT is load-bearing, and rehydrates detail on demand. Use when the session is long, many turns, large file reads, or nearing the context limit. Trigger phrases: 'context is full', 'remember the beginning', 'long session', 'summarize what we did', 'we are losing track'.
