## What it does

Forced-explicit ambiguity gate for weak/free models. Before ANY execution step, produce a mandatory JSON contract with ambiguity_score, assumptions_made, missing_info, clarifying_question. If ambiguity_score > 0.4, BLOCK execution and route the clarifying question to HITL (or a frontier model) instead of guessing. Use whenever a task is underspecified, vague, placeholder-laden, or when the generator model is small and cannot be trusted to self-stop.
