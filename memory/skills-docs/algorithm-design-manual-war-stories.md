## What it does

Applies Steven Skiena's Algorithm Design Manual 'war manual' to real-world problems: classify the problem type first, consult the problem catalog for the proven approach (sorting, hashing, search, strings, graph, combinatorial search), then lift a War Story lesson before optimizing. Stops the failure mode of jumping straight to a clever algorithm when the catalog says use the boring one. Use when the user says 'which algorithm fits this problem', 'war story', 'problem catalog', 'this feels like a textbook problem', 'what is the right approach', 'brute force then optimize', or hands a real engineering problem that needs the practical (not theoretical) algorithm choice. Pairs with: clrs-algorithm-mastery, algorithm-design, algorithmic-math-reasoner, code-execution-guided-swemaster.
