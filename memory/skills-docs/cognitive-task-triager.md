# cognitive-task-triager

- **Source file:** `.opencode/skills/cognitive-task-triager/SKILL.md`

## What it does

Analyzes task complexity and assigns execution to the optimal LLM tier (Routine, Code, Long-Context, Critical Reasoning) before any model call. Prevents wasting high-cost tokens on trivial tasks and NEVER sends complex reasoning to a weak 13B-active-parameter model. Use when deciding which model should execute a task, when a prompt mixes easy and hard sub-tasks, when context is huge, or when ambiguous requirements must be surfaced. Trigger phrases: 'which model should handle this', 'route this to a smarter model', 'task complexity', 'cognitive triage', 'cheap vs expensive model'.
