## What it does

Applies Martin Fowler's Patterns of Enterprise Application Architecture (PoEAA) to automation and service code: the Layered Architecture, Domain Model vs Transaction Script vs Table Module, Identity Field, Unit of Work, Repository, Lazy Load, and the service layer. Guides choosing the right architecture shape for the problem size and avoiding the data-mapper-and-repository-everywhere anti-pattern for small systems.
