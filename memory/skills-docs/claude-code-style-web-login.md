## What it does

Brows the web and logs into websites with the USER'S OWN accounts on THEIR device, replicating exactly how Claude Code does it — a visible local browser (Playwright MCP) with a PERSISTENT profile so one real login (user types credentials/2FA on screen) carries cookies across sessions, plus optional escalation to the user's real Chrome (CDP) and a registry of reused sessions. Use whenever the task needs 'my account', 'logged in state', 'login to <site>', 'reach my dashboard', 'check my orders/messages/dashboard', or any site that blocks anonymous scraping. Pairs with playwright MCP (mcp 'playwright': browser_navigate / browser_snapshot / browser_click / browser_type / browser_press_key / browser_wait / browser_screenshot / browser_close) + site-login-session-registry + hitl-captcha-auth-handler + desktop-gui-controller.
