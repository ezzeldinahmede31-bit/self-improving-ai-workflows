## What it does

Autonomous meta-skill that MEASURES the current model against a live leader with real model calls on deterministic probes, pulls real weaknesses from the audit trail (FeedbackLoop rejections, HITL quirks), and promotes ONLY verified guard rules into machine-readable rules.json that the SecurityGate enforces at runtime. Honest loop: [measure gap -> extract real weaknesses -> trial current model against the exact regression probe -> promote only on pass].
