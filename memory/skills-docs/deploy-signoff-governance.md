## What it does

Run the final human sign-off ceremony for financial or sensitive deploys: authorization tiers (what needs a human, what never auto-approves), the evidence packet (gates verdict, execution proof, rollback plan), single-use token ceremony, and atomic rollback. Use when deploying anything that moves money, deletes data, touches production credentials, or publishes a workflow that agents will act on.
