## What it does

When a fast model must reach frontier-level certainty, delegate VERIFICATION (not generation) to a stronger model: generate cheap here, then have the strongest available model judge, attack, or certify the result. Exploits the research finding that a good verifier beats a good generator — the flash model generates fast/free, the elite model only reads and adjudicates. Use when 'get a second opinion', 'have a stronger model review this', 'certify this is right', 'I want an expert check'.
