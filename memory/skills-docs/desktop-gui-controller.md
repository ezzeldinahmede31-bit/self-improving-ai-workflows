## What it does

Controls the user's real X11 desktop session (DISPLAY=:0) like a human coworker: list/focus/resize windows with wmctrl, send keyboard and mouse events, capture screenshots as evidence, manage clipboard, and launch apps. Use whenever the task needs the actual machine, not a headless VM: 'open my browser', 'type into this window', 'look at my screen', 'click there', 'what window is open', 'use my device'.
