## What it does

Logs into websites ONCE, persists the authenticated browser session as a named profile in a registry, and reuses it on later runs so the user is not asked for credentials again. Orchestrates first-login (vault creds + real human 2FA confirmation) and session renewal (cookie expiry, re-auth).
