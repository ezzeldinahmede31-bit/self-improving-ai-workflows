## What it does

Applies Google's Site Reliability Engineering (SRE) and The DevOps Handbook to automation and services: define SLIs (real measured indicators), set SLOs (targets), manage an error budget (the allowable downtime that balances reliability vs feature velocity), eliminate toil through automation, run blameless post-mortems, and use monitoring with meaningful alerts (no alert fatigue). Encodes the SRE mindset: reliability is a product decision with a budget, not an engineering aspiration. DevOps adds: the Three Ways (flow, feedback, continual learning), value stream mapping, deployment pipeline automation, small-batch deployments with fast rollback, monitoring and alerting as feedback, and the cultural practices that make automation stick.
