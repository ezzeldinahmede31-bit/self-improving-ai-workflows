# n8n-credential-security-guard

- **Source file:** `.opencode/skills/n8n-credential-security-guard/SKILL.md`

## What it does

Prevent ANY API key, secret, token, or password from being written into n8n node parameters, expressions, or Code-node source. Use ONLY whenever generating or editing n8n nodes that need authentication (HTTP, Telegram, OpenAI, Stripe, etc.). Forces exclusive use of pre-registered n8n Credential IDs.
