## What it does

Applies Steve Krug's Don't Make Me Think to web usability: a page is good if a user can say 'of course' — self-evident design, no thinking required. Covers the first rule of usability (don't make me think), the scan-don't-read behavior of web users, satisficing (good-enough clicking), designing for skimming with clear visual hierarchy, and the killer home page lesson. Includes practical techniques: the trunk test (can you identify a site in five seconds), conventions over novelty, and the instruction that usability testing with three users catches the big problems cheaply. Use when the user says 'is my site easy to use', 'usability review', 'don't make me think', 'Krug', 'why do users not understand my page', 'trunk test', 'visual hierarchy', 'scan don't read', 'satisficing', 'design for skimming', or when designing any page, landing page, or dashboard that users must grasp without a manual.
