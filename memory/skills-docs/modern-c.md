## What it does

Applies Jens Gustedt's Modern C to write safe, portable, maintainable C11/C17: explicit types, bounds-aware design, memory ownership discipline, error handling as data, and checked arithmetic. Encodes the modern idioms that eliminate the classic C failure modes (silent overflow, off-by-one access, uninitialized state) so C code is correct by construction.
