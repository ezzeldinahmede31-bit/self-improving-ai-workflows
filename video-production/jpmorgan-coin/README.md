# JPMorgan COiN — Story 01

A 30-second, 1920×1080 Remotion motion-design starter.

## Run locally

```bash
npm install
npm run dev
```

Open the Remotion Studio preview, inspect the scenes, and adjust timing/design before final export.

## Render

```bash
npm run render
```

Output: `out/jpmorgan-coin-story-01.mp4`

## Preview still

```bash
npm run preview
```

## Creative structure

1. Title / “The 360,000 Hour Problem”
2. The manual contract-review bottleneck
3. COiN introduced as the intelligence layer
4. Document extraction visual
5. Time-saving impact
6. Closing question

## Important production notes

- This is an initial code-built motion-design pass, not a finished, reviewed master.
- It uses original CSS/SVG-built visuals. No Canva stock assets have been imported.
- The 360,000-hours figure is the commonly cited annual time-saving claim; verify the exact wording and source before publishing.
- No licensed music or sound effects are bundled. Add cleared sound design in the finishing pass.
- The project is 30 seconds at 30 fps, 1920×1080. Change the Composition dimensions to 3840×2160 for a 4K render after validating performance.
