## A. التقويم والحجوزات
| الميزة | الحالة | الدليل |
|---|---|---|
| حجز جديد + بحث + إلغاء + تأجيل | 🟠 | مسارات موجودة؛ أُصلحت الأسلاك الميتة والملكية والسaga — التنفيذ الحي محجوب (تقويم تجريبي) |
| مدد الخدمات/الأطباء/الساعات | ✅ | جدول بيانات + مرآة مخبوزة + اختبار منطق |
| منع التداخل الأساسي | 🟡 | فحص النافذة + قفل INCR (أُثبت ذريته حيًا على Redis معزول)؛ تداخل المدد المختلفة نظريًا فقط |
| قوائم انتظار + ملء الملغاة | 🟡 | عروض Freed-Slot موجودة؛ إعادة العرض التلقائي ❌ (Backlog) |
| حالات الحجز الكاملة (مؤكد/وصل/مكتمل/غاب) | 🟠 | مؤكد/ملغي موجود؛ وصل/مكتمل/غاب ❌ (Backlog، تحتاج إدخال طاقم) |
| رقم دور يومي | 🟠 | كان ميتًا → أُعيد توصيله + عدّاد يومي؛ الترقيم المزدوج عند طبيبين: رقم واحد يومي مشترك (موثق) |

| استرداد بعد فشل جزئي | 🟠 | مسارات التعويض مضافة + اختبار منطق؛ التنفيذ الحي محجوب |

## B. الاستقبال والذكاء
| عربي أولًا + إنجليزية | 🟡 | موجه عربي + Whisper ar؛ اختبار محادثة حي 🔒 (يحتاج جلسة Telegram تجريبية) |
| أسعار/ساعات معتمدة فقط | 🟠 | قاعدة _fallback + حارس DEMO — فعالية الحارس ضد أسعار قديمة: تحتاج مراجعة بشرية أول إطلاق |
| حد أدنى للبيانات + توضيح | ✅ | حقول الإدخال + رسائل نقص |
| تصعيد بشري | ✅ | مسارات موجودة + كلمات طبية حرجة في الموجه |
| منع اختلاق الحجوزات | 🟠 | قاعدة مُضافة + اختبار فشل-الأداة منطقيًا؛ سلوك LLM الحي 🔒 |
| prompt injection | 🟡 | قاعدة مُضافة + اختبار حقن-ملكية ناجح؛ اختبار حقن-موجه شامل 🔒 (يحتاج جلسة LLM حية) |
