# INTEGRATION_E2E.md — التكاملات (n8n/Redis/Calendar/Telegram)

## ما نُفذ فعلًا (قراءة آمنة فقط)
- `n8n list:workflow` + `export:workflow --all --separate` → 48 ملفًا ✅.
- SQLite read-only: 23 credential (أسماء/أنواع)، executions للتحقق ✅.
- Redis معزولة (حاوية مؤقتة حُذفت): سباق/TTL/restart ✅.
- OpenRouter: استدعاءات تقييم الذكاء ($0.015، مسجلة) + إثبات نفاد الطبقة المجانية (402) ✅.
