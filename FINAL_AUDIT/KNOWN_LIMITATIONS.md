# KNOWN_LIMITATIONS.md — القيود والمخاطر المتبقية

1. **لا إنتاج حي بعد**: كل الكتابة الخارجية (تقويم/Telegram) غير مختبرة حيًا — يلزم تقويم تجريبي + محادثة اختبار (منك).
2. **التزامن النظري**: سباق Redis مُثبت حيًا؛ سباق التقويم الخارجي المتزامن غير مُثبت (يحتاج بيئتين).
3. **LLM غير حتمي**: قواعد عدم الاختلاق تعتمد سلوك الموديل — راقب أول 100 محادثة حقيقية يدويًا.
4. **الملكية بالـ chat/phone**: حجوزات قديمة بلا chat ملزم تصبح غير مرئية للبحث الجديد (مقصود أمنيًا) — تُعالج عبر الطاقم.
5. **متعدد الأطباء/الفروع**: رقم الدور يومي مشترك؛ الفصل الكامل منتج مستقل (Backlog).
6. **PDPL**: يلزم صياغة موافقة + مسؤول حماية + مراجعة محامٍ قبل أي مريض حقيقي.
7. **اعتماد خارجي**: Google/OAuth/Telegram — أي تغيير من مزود يكسر المسارات (فحص الصحة ينبه فقط).
8. **الأداء**: غير مُختبر تحميليًا (100 متزامن) — مطلوب قبل أول حملة.
9. **النسخة الاحتياطية**: tgz غير مشفرة — لا ترفعها لأي سحابة؛ فعّل تشفيرها.
10. **التقارير المالية**: ممنوعة حتى توجد مدفوعات حقيقية (لن نخترع أرقامًا).
