## تبرير إزالة requiresHumanApproval (مراجعة §11 المطلوبة — كل واحدة)
| العقد | النوع | لماذا آمن الحذف |
|---|---|---|
| Release Slot Claim/Failed/Unverified (book) | تحرير قفل داخلي | الحذف يمنع التنظيف → تسرب الأقفال. لا تأثير مريضي. البديل: TTL موجود أصلًا. |
| Delete Alt Cache (book) | تنظيف كاش بدائل | بيانات مؤقتة TTL. لا تأثير مريضي. |
| Release New/Failed New (resched) | تحرير قفل | نفس منطق الأقفال أعلاه. |
| Delete Old Event/Remind/Index (resched) | حذف حجز قديم **بعد** إنشاء الجديد والتحقق | محمي ببوابة الملكية + cutoff + saga + سجل audit. الموافقة هنا = تجميد التأجيل كله (الميزة نفسها). |
| Delete Calendar/Reminder/Index (cancel) | حذف إلغاء مطلوب | محمي ببوابة الملكية + cutoff 24h + سجل. الإلغاء هو الفعل المعتمد أصلًا. |
| Clear Alert Marker / Cleanup / Offers deletes | صيانة داخلية | لا تأثير مريضي مباشر. |
**ما لم يُمس**: بوابة القطع 24h، سر الطاقم، بوابات الملكية، تصعيد الطوارئ — كل آليات الموافقة/الأمان الحساسة باقية وتُختبر.
