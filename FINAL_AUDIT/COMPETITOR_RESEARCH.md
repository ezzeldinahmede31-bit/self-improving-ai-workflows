# COMPETITOR_RESEARCH.md — مصفوفة المنافسين (اطّلاع 2026-10-11)

منهجية: المميزات من الوثائق الرسمية فقط. الشكاوى مصنفة: REPEATED (3+ تقارير) / SINGLE / UNVERIFIED. التفاصيل الكاملة في مخرجات فرق البحث المحفوظة بالجلسة.

## NexHealth (أمريكا، سحابي)
- الفئة: عيادات + DSO. حجز أونلاين/waitlist/تذكيرات/مدفوعات (2.6%+$0.07 طرفية) / تحليلات Insights / EHR ثنائي الاتجاه. السعر: ~$350/مزود/شهر (غير رسمي — التسعير بالعرض فقط). المصادر: nexhealth.com/features/*.
- الشكاوى: **أسعار متصاعدة وعقود صارمة (REPEATED)** — "رخيص أولًا ثم لا يُحتمل"، رفض استرداد؛ دعم محدود الساعات (REPEATED)؛ إعداد شهر لعيادة فردية (SINGLE).
- الدرس لنا: سعر جنيه ثابت بلا تصعيد + دعم بتوقيت القاهرة + دفعات جزئية بأي مبلغ.

## Weave (أمريكا، اتصالات + دفع)
- الفئة: عيادات أسنان. حجز/تذكيرات SMS/دفع نصي/قوائم انتظار/تطبيق جوال. المصدر: getweave.com.
- الشكاوى: **التجديد التلقائي ورفض الإلغاء (REPEATED)** — "يستمرون بالخصم بعد انتهاء العقد"؛ دعم سيئ (REPEATED)؛ فشل نصوص التأكيد (SINGLE).
- الدرس: اشتراك شهري قابل للإلغاء بضغطة + سجل تسليم مرئي لكل رسالة + واتساب أولًا لا نظام هاتف مفروض.

## Jane App (كندا)
- الفئة: عيادات صغيرة. حجز ذاتي/تذكيرات/مدفوعات (2.85%+$0.25)/تقارير. السعر الرسمي: $59-99/شهر. المصدر: jane.app/pricing.
- الشكاوى: **تقارير مالية ضعيفة (REPEATED)**؛ منحنى إعداد صعب (REPEATED)؛ غالٍ على الفردي (REPEATED)؛ تأكيد بريدي يفشل أحيانًا (SINGLE).
- الدرس: تقارير يومية جاهزة (تحصيل جنيه، no-show، متابعة) + قوالب عربية مهيأة + تأكيد واتساب بزر.

## Open Dental (أمريكا، مفتوح)
- الفئة: كل الأحجام. جدولة/استدعاء/Web Sched/فوترة/تصوير/API رسمية. السعر الرسمي: $199/موقع/شهر + حزم. المصدر: opendental.com.
- الشكاوى: تعقيد التعلم (REPEATED)؛ محاسبة صعبة القراءة (REPEATED)؛ دعم مدفوع منفصل (SINGLE). GitHub mirror: قضيتان بناء فقط — لا تتبع علني للأخطاء.
- الدرس: بساطة الواجهة العربية + سعر شامل (واتساب ضمنه لا إضافة) + عمل دون VPN.

## Dentrix Ascend (Henry Schein)
- الفئة: DSO/سلاسل. سحابي + API Exchange (700+ endpoint) + ذكاء imaging. السعر: عرض فقط، تنفيذ 4-6 أسابيع. المصدر: dentrixascend.com.
- الشكاوى: **ترحيل مؤلم للمحاسبة (REPEATED)**؛ تكاليف إضافية لكل خطوة ($5k نقل ملكية) (REPEATED)؛ خطوات كثيرة ومعقد (REPEATED).
- الدرس: ضمان ترحيل بفحص تطابق + تقارير مدمجة بلا منتج تحليلات ثانٍ + عمل مع إنترنت متقطع.

## CareStack (أمريكا/الهند)
- الفئة: DSO. جدولة/تذكيرات/فوترة/API مفتوحة. السعر الرسمي: من $829/شهر. المصدر: carestack.com/pricing.
- الشكاوى: خطوات كثيرة للمهمة (REPEATED)؛ إعداد أصعب من المتوقع (REPEATED)؛ دعم متأخر أحيانًا (SINGLE).
- الدرس: حجز→تأكيد→دفع في خيط واتساب واحد + checklist عربي + سعر عيادة واحدة بالجنيه.

## Doctolib (فرنسا/ألمانيا)
- الفئة: حجز مرضى + فيديو. تطبيق 4.8 (776K تقييم). المصدر: doctolib.fr.
- الشكاوى: فلاتر كاذبة (لغة/تأمين) (REPEATED كموضوع)؛ فيديو بلا رد ولا تعويض واضح (SINGLE)؛ دعم نادر (SINGLE).
- الدرس: تحقق من حقول الملف قبل العرض + تذكير مزدوج بزر إلغاء + سعر وطريق استرداد معلنان.

## Zocdoc (أمريكا)
- الفئة: سوق حجز. عمولة لكل مريض جديد حتى لو لم يحضر (رسمي). المصدر: zocdoc.com/about/newpricing.
- الشكاوى: **رسوم على حجوزات ملغاة/خاطئة بلا طعن (REPEATED)**؛ حجوزات مزدوجة من المزامنة (REPEATED)؛ زيادات سعرية (SINGLE).
- الدرس: **لا عمولات إطلاقًا** — اشتراك جنيه ثابت؛ رفض مجاني بلا رسوم داخل مهلة؛ تقويم كرسي واحد مصدرًا للحقيقة.

## Vezeeta (مصر/الشرق الأوسط)
- الفئة: سوق حجز + صيدلية + زيارات. تطبيق المرضى 4.4 (131K). المصادر: vezeeta.com + بنودها (لا عمولة معلنة للعيادات علنًا).
- الشكاوى: دعم لا يُرد بعد فشل مدفوع (SINGLE)؛ رسوم متغيرة ولا توافر (SINGLE)؛ عيادات تتجاهل حجوزات التطبيق (SINGLE).
- الدرس: دعم بشري واتساب + هوت لاين معلن + كل إلغاء/استرداد مسجّل؛ المواعيد ملزمة بتأكيد واتساب نفس اليوم.

## CliniDo / Medastik (مصر)
- CliniDo: حجز بسيط + استشارة صوتية، مجاني للمريض. الفجوة: وحدات تخصصية قليلة.
- Medastik: سلاسل أسنان، سير محلية. الفجوة: نطاق ضيق.
- الدرس: تخصص أسنان عميق (مخطط أسنان، مدد خدمات) + عربي كامل — وهو ما نبنيه.

## خلاصة التموضع ضد الكل
لا أحد يقدم: واتساب عربي أولًا + سعر جنيه ثابت بلا عمولات + تشغيل أيام + تأكيد بزر + سجل تدقيق. هذه خاناتنا الأربع.
